# Contributing

Work from `develop`; do not push directly to `main` or `develop` after branch protection is enabled.

Use the project branch convention:

`feature/<role>/<description>`

Examples:

- `feature/backend/mqtt-subscriber`
- `feature/backend/telemetry-history`

Before opening a pull request, run `python -m pytest -q`, attach API/database evidence, and request at least one teammate approval.

# Contributing

Work from `develop`; do not push directly to `main` or `develop` after branch protection is enabled.

Use the project branch convention:

`feature/<role>/<description>`

Examples:

- `feature/backend/mqtt-publisher`
- `feature/backend/rain-gauge-reader`

Before opening a pull request, compile the affected sketch/firmware, record the selected ESP32 board, and include test evidence. At least one teammate must approve before merging.
